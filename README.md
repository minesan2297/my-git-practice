# My Git Practice

## Dự án: Trang web giới thiệu sách (Bootstrap Demo)

Trang web tĩnh giới thiệu về sách được xây dựng bằng HTML5, CSS3 và Bootstrap 4 theo yêu cầu bài học.

### Các thành phần chính của trang:
1. **Header & Book Overview**: Thanh điều hướng (Navbar) cố định khi cuộn trang, giới thiệu tổng quan cuốn sách "Exciting Adventure".
2. **Author**: Giới thiệu về tác giả kèm hình ảnh và thông tin chi tiết.
3. **Features**: Các đặc điểm nổi bật kèm hiệu ứng nhảy số tự động (Number Counter Animation).
4. **Prices**: Bảng báo giá các gói mua sách (PDF, E-book,...).
5. **Download**: Giới thiệu ứng dụng đa nền tảng (Desktop & Mobile).
6. **Reader's Say**: Đánh giá và nhận xét từ độc giả (sử dụng Carousel slider).
7. **Footer**: Thông tin liên hệ, đăng ký nhận bản tin (Newsletter) và mạng xã hội.

### Công nghệ sử dụng:
- **HTML5 & CSS3**
- **Bootstrap 4.6**
- **Font Awesome 5**
- **jQuery 3.6** (xử lý sticky navbar và hiệu ứng counter)
- **Responsive Web Design**: Tương thích tốt trên Desktop, Tablet và Mobile.
